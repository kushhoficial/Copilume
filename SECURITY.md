# Segurança e privacidade

Não publique dados sensíveis em issues. Para relatar problemas, use uma reprodução com dados sintéticos e descreva a falha sem revelar o conteúdo real do clipboard. Para falhas de segurança, use a aba Security do repositório oficial e o relato privado de vulnerabilidade quando estiver habilitado. Não publique detalhes exploráveis antes de conversar com o mantenedor.

O histórico persistido é opcional e não tem criptografia própria. O projeto respeita marcações conhecidas de conteúdo confidencial; não identifica toda senha. Builds ad hoc não são notarizados. Nenhum processo de atualização remota está incluído nesta versão.
